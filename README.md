# 🧶 Дом вязанных историй (Knitly)

## ✨ Особенности

- **Три роли пользователей**: Покупатель, Мастер, Администратор.
- **Каталог товаров** с фильтрацией по категориям, технике и цене.
- **Корзина** и **избранное**.
- **Оформление заказов** с расчётом доставки и налогов.
- **Личный кабинет** покупателя и мастера.
- **Блог** для мастеров (создание постов, лайки, комментарии).
- **Мастер-классы** (онлайн и офлайн) с записью участников.
- **Чат поддержки** и **база знаний**.
- **Административная панель**: управление пользователями, модерация товаров и постов, управление каталогами пряжи и категорий.
- **Аутентификация**: email/пароль + OAuth (Google, Яндекс, VK).
- **Адаптивный дизайн** (мобильные устройства, планшеты, десктопы).
- **Анимации** с использованием Framer Motion.

## 🛠 Технологический стек

### Backend
- **Next.js 16** – серверный рендеринг, API Routes, App Router.
- **NextAuth.js** – аутентификация (JWT, OAuth).
- **Supabase (PostgreSQL)** – база данных.
- **Selectel S3** – объектное хранилище для изображений.
- **Node.js** – среда выполнения.

### Frontend
- **React 19** – пользовательский интерфейс.
- **TypeScript** – типизация.
- **Tailwind CSS 4** – стилизация.
- **Framer Motion** – анимации.

### Клиент-серверное взаимодействие
- **REST API** (JSON).
- **JWT** – аутентификация.
- **HTTPS** – защищённое соединение.

### Инструменты разработки
- **ESLint** – проверка кода.
- **Postman** – тестирование API.
- **Git** – контроль версий.

## 👥 Функциональные возможности

### Покупатель
- Регистрация и авторизация (email + SMS, Google, Яндекс, VK).
- Просмотр каталога с фильтрацией и поиском.
- Управление корзиной и избранным.
- Оформление заказов (адрес доставки, промокоды).
- Просмотр истории заказов и их статусов.
- Оставление отзывов и комментариев.
- Подписка на мастеров.Запись на мастер-классы.
- Чат поддержки.

### Мастер (дополнительно к покупателю)
- Управление товарами (добавление, редактирование, удаление, загрузка изображений).
- Управление ассортиментом пряжи.
- Просмотр и изменение статусов заказов на свои товары.
- Ведение блога (создание, редактирование, удаление постов).
- Создание мастер-классов (онлайн/офлайн).
- Просмотр списка участников мастер-классов.
- Управление профилем мастера (описание, индивидуальные заказы).

### Администратор
- Дашборд со статистикой (пользователи, заказы, выручка).
- Управление пользователями (блокировка, смена ролей, верификация мастеров).
- Модерация товаров и постов (одобрение, отклонение, блокировка).
- Управление каталогом пряжи (CRUD).
- Управление категориями товаров (иерархическая структура, иконки).
- Обработка обращений поддержки (чаты, тикеты).
- Ведение базы знаний (статьи, категории).

## 🧩 Архитектура

Проект построен на клиент-серверной архитектуре с использованием Next.js App Router:

- Клиентская часть – React SPA с серверным рендерингом (SSR) для SEO.
- Серверная часть – API-маршруты (Next.js) обрабатывают запросы и взаимодействуют с Supabase и S3.
- База данных – Supabase (PostgreSQL) хранит все данные.
- Хранилище – Selectel S3 для изображений и медиафайлов.
- Аутентификация – NextAuth.js (JWT, OAuth).
- Внешние сервисы – nodemailer (email), sms.ru (SMS).

## 🧪 Тестирование

- Функциональное тестирование – охвачено 24 сценария (регистрация, каталог, корзина, заказы, модерация, чаты и др.).
- Нагрузочное тестирование – проведено с помощью Apache JMeter (100 одновременных пользователей).
- Тестирование безопасности – XSS, SQL-инъекции, CSRF.
- Регрессионное тестирование – после исправления ошибок.
